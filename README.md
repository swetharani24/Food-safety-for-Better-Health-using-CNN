## 📖 Project Overview

- 🧠 Deep Learning-based image classification system for food recognition.
- 🔁 Uses **Custom CNN** and **Transfer Learning** models (VGG16, ResNet50).
- 🌐 Designed for real-time prediction via web interface.

---

## ✨ Project Highlights

| Feature | Description |
|---------|-------------|
| 🏗️ Custom CNN | Architecture built from scratch |
| 🔄 Transfer Learning | Using VGG16 and ResNet50 |
| 🔀 Data Augmentation | For improved generalization |
| 🎯 High Accuracy | Multi-class classification |
| 🚀 Deployment Ready | Streamlit / Flask compatible |
| ☁️ Cloud Compatible | Deployable on Render |

---

## 🤖 Models Implemented

### 🔷 Custom CNN
> Convolution → MaxPooling → Flatten → Dense layers

### 🔶 VGG16
> Pretrained on ImageNet for strong feature extraction

### 🔴 ResNet50
> Deep residual network solving the vanishing gradient problem
